# Mobile apps

My Android apps from the Google Developer Challenge Scholarship and high school, collected as submodules.

- [zara-fashion-app](https://github.com/dianapaula19/zara-fashion-app)
- [score-keeper-app](https://github.com/dianapaula19/score-keeper-app)
- [quiz-app](https://github.com/dianapaula19/quiz-app)

Clone everything with `git clone --recurse-submodules`, and get the latest version of each
project with `git submodule update --remote`.
